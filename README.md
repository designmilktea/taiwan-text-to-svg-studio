# Taiwan Text to SVG Studio

An interactive browser-based SVG typography editor for Traditional Chinese and English.

## Features

- Nine text path styles: Arch, Downward Curve, Wave, Circle, Straight, Heart, Star, Triangle, and Rectangle.
- Adjustable font family (including Traditional Chinese Google Fonts), font weight, size, letter spacing, and text color.
- Live preview and SVG code copying/download.
- Single-file HTML application with no build step.

## Use

Open [index.html](./index.html) in your browser. Google Fonts require an internet connection. Downloaded SVG files contain text that references fonts, so convert text to vector outlines in Inkscape or Illustrator for font-independent production use.

## Publish via GitHub Pages

Open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. Your site URL will be `https://designmilktea.github.io/taiwan-text-to-svg-studio/` once GitHub finishes publishing.
